Installation

nvcl-kit is available on PyPi, and can be downloaded with pip:

pip install nvcl-kit

Upgrading nvcl-kit

New versions of nvcl-kit are released frequently. You can upgrade to the latest edition on PyPi using the --upgrade flag:

pip install --upgrade nvcl-kit
