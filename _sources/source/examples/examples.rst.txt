Examples
========

The examples in this section demonstrate how to use ``nvcl-kit`` to access and filter borehole data from
the NVCL. Each example is designed to be self-contained, providing step-by-step instructions and code
snippets to help you get started quickly.

A more comprehensive view of ``nvcl-kit`` can be found in the :doc:`API documentation <../nvcl_kit>`.
